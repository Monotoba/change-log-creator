# Contributing

Install with `python -m pip install -e .` and run
`python -m unittest discover -s tests -v`. Git must be on PATH.

Keep changes focused and add tests using temporary Git repositories. Describe the
problem, expected behavior, and validation in your pull request. Do not commit
private history, credentials, build output, or virtual environments. Bug reports
should include OS, Python/Git versions, and minimal reproduction steps.

Contributions must be compatible with BSD-2-Clause. Useful improvements include
Markdown fence escaping and optional curated release-note formatting.
